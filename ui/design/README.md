# BGM UI Design System

## Identity
Black Gold Messenger (BGM)

## Visual Direction
Luxury Technology

## Base
Dark black interface.

## Primary Accent
Gold / glowing gold used selectively for active states,
highlights, primary actions, and BGM identity elements.

## Typography
Primary font: Atkinson Hyperlegible

Target body/chat size:
16–18 px

Supported text sizes:
- Normal
- Large
- Extra Large

## Design Principles
- Clear
- Readable
- Elegant
- Lightweight
- Low-RAM friendly
- Minimal animation
- Minimal gradients
- No excessive glow
- No excessive gold
- No game-like neon styling

## Navigation Foundation
- Chat
- World
- Radio
- Profile

## UI Rule
The UI layer must remain modular and must not modify
the frozen BGM core engine without an explicit integration step.
